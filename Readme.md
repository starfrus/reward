# 1. Название проекта и описание идеи
## Название: **Reward**

Проект решает мои личные проблемы достижения целей и поощерения себя за хорошую работу.

## Идея
- Этот проект создан что бы сфокусироваться на достижения цели через маленькие шаги 
- Поощерение себя за достижение поставленых целей
- Ключевые цели:
    - Постановка цели
    - Привящка к цели маленькие шаги(действия) для достижения цели
    - Отслеживание прогресса
